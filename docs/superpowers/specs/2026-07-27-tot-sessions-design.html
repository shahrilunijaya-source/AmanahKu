Motion

Everything under 300ms. No ease-in, nothing entering from scale(0). All transforms are disabled under prefers-reduced-motion.

ElementTreatmentWhy
Row hoverDate tile fills red, lifts 1px; row washes to tint; name goes red. 170msThe date is already under the eye. Lighting it costs nothing to notice.
Row pressscale(.96) on the tileMakes the tile read as a key you push.
Row expandgrid-template-rows: 0fr → 1fr, 280msLayout, not transform. No transform equivalent exists for unknown height. Click-triggered, so it never runs in a busy frame.
Chevronrotate(180deg), 220msDirection of travel.
Emoji pressscale(.94), 140ms ease-outDirect manipulation needs press feedback.
Year switchColour only, 160msThree targets. A sliding indicator would be decoration.
Easingcubic-bezier(.23,1,.32,1)Strong ease-out. The CSS built-ins are too weak to read as intentional.

Colour

No new colours. Every value below already exists in resources/css/app.css. The one deliberate decision is using the brand red as a full field, which is also the app's error colour. TOT is the single screen where red means occasion rather than fault.
