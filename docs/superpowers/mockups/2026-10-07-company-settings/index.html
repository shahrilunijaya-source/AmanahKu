Company settings, polished

Same screen, same fields, same save endpoints. What changes is how it is arranged and how each part tells you its state.

  • One column with a section index. Today one tall card sits on the left and eleven cards squeeze into a 380px column on the right, so branch forms wrap into three lines and the left side goes blank halfway down. Now every card gets the full width and a sticky index jumps between them (a scrolling chip bar on phones). The amber dot flags a section that needs attention.
  • Workspace profile is grouped. Plan, category, ID and members move to the top as a read-only strip. Fields fall into Company, Login page, Contact and Payroll journal. The journal codes used to sit between Email and Website.
  • Login page gets a live preview. Logo, brand colour, secondary colour and welcome message all feed the login page, so they sit next to a small preview that updates as you type. Colours get a real picker next to the hex field. The broken logo image and the raw "Choose File" input are replaced by an upload tile.
  • Statutory says if payroll is blocked. The three numbers a payroll run needs (E number, KWSP, PERKESO) show as a readiness bar at the top. Each agency gets its own row.
  • Approval shortcut reads as a sentence with an on/off switch, instead of "leave blank to turn this off".
  • Lists are quieter. Edit and Delete become icon buttons that show on hover (always on touch), so the red Delete links stop competing with the Save buttons. Staff levels show their seniority number as a badge, employment types show the No clock-in stamp.
  • Features use switches and the Locked badge becomes a neutral stamp with a lock, since red is only for actions.
  • Every field gets a focus ring. Most inputs today set outline:none with nothing in its place, so a keyboard user cannot see where they are.
