# Culture Pack (CR-22 to CR-31) – Personality, Surprise, Team Interaction

Read this before implementing any CR from CR-22 to CR-31.

These are deliberately not scoring systems. No points, no leaderboards, no management reporting.

Shared principle: opt-in, anonymous where stated, never on management dashboards, and every animation / cheeky message can be switched off in profile settings (one toggle: 'Keep it plain').

**Run note:** the 'Keep it plain' toggle is specified inside CR-31 but is pulled forward into session S04, because CR-13 and CR-20 already ship animations with no off switch. By the time any Culture Pack CR is built, the toggle already exists. Wire to it, do not re-create it.
