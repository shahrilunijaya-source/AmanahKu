# CR-12 – BUG: Dashboard Header Covered by Top Bar

| Field | Value |
|---|---|

| Priority | High |
| Tracker status | DONE |
| Owner | Shazwan |

## Issue
On the Dashboard, the greeting line ('Good morning, Yati.') and the date/status line ('Saturday, 5 September 2026, not clocked in yet.') are rendered underneath the sticky top bar (search / EN-BM / Knowledge / Messages / profile). Text is partially blurred and cut off; the settings gear is also half hidden.

## Also observed
Sidebar 'TODAY' still shows Fri 4 Sep while the main page shows Saturday, 5 September, the sidebar date does not refresh after midnight without a reload. Clock-in state should follow the same date.

## Fix
1. Add top padding / offset to the main content equal to the sticky header height (or make the header non-overlapping via flex layout) so the greeting row is fully visible at page load and after scroll-to-top.
2. Check the same on all pages with a page-title row (My Work, Timesheet, Events, Learning) and on narrower widths where the header wraps taller.
3. Sidebar date/clock-in widget should re-evaluate the date on focus or at midnight (timer), not only on reload.

## Acceptance
1. Open Dashboard at 100% and 125% zoom, desktop and 1366px width, greeting and date line fully visible, not overlapped.
2. Scroll down then back to top, still not covered.
3. Leave the tab open past midnight, sidebar date changes without reload.
