# CR-15 – Move 'My Profile Test' to the Dashboard

| Field | Value |
|---|---|
| Module | Dashboard / Navigation |
| Priority | Low |
| Tracker status | DONE |
| Owner | Shazwan |
| Target | 11 Sep 2026 |
| Run status | Built before CR-32. Session S04 confirms it sits in the left column after My work summary |

## Requirement
Remove My Profile Test from the left navigation (currently under Learning). Show it on the Dashboard instead as a card: the user's working-style result (e.g. Fox 60%, 'Strategic and resourceful. Adapts fast.') with the four-animal breakdown, and a 'Take / retake test' action if not done yet.

## Why
It is a one-time personal check, not a daily menu item; leaving it in the sidebar adds clutter. On the Dashboard it becomes a fun, visible part of the person's profile and sits naturally with the birthday and awards cards (CR-13/14).

## Scope
1. Remove the sidebar entry; keep the route reachable from the Dashboard card and from the user profile page.
2. Dashboard card (compact, beside 'Current month summary'): animal emoji, style name, one-line description, mini bars for Rabbit / Tortoise / Fox / Sloth, link 'View full profile' (About yourself / Working style / Colour tabs).
3. If the test is not taken: card shows 'Discover your working style, 3 min' with a Start button.
4. Optional: teammates' animals visible on 'My staff' view so PMs see the mix in their team.

## Acceptance
1. Left panel no longer shows 'My Profile Test' under Learning.
2. Dashboard shows the Fox card for Yati with 60/30/10/0 breakdown; clicking opens the full profile test page.
3. A user who hasn't taken the test sees the Start prompt instead.
