## Requirement
The Learning slot detail page (e.g. 'Google AI Antigravity – Solehin – Saturday 3 January 2026') does not match how the programme actually runs. It is a monthly TOT (Training of Trainers) session on Saturday, with a chair, several presentations and demos, attendance, Q&A per slot, and follow-up actions, not one title with one presenter.

## Reference
Nota Perbincangan TOT 1 Ogos 2026: 1 Saturday session, Pengerusi (Ahmad Kussairi), 3 presentations + 1 test-stage demo, each with pembentang and sokongan, 19 attendees with absentee reason, Perbincangan & Maklum Balas per slot, 4 Keputusan/Tindakan with owner and target, and agenda for next month.

## Data model
**Session** (one per Saturday): date, type = TOT Bulanan, Pengerusi/host, Nota Perbincangan (PDF/link), attendance list (hadir / tidak hadir + sebab), next-month agenda.

**Slot** (many per session, ordered): title, kind (Pembentangan / Demonstrasi / Sambungan), pembentang (Solo/Team) + sokongan, format tag (Slide/Demo), status (Rasmi / Peringkat ujian), summary, Perbincangan & Maklum Balas (discussion thread per slot), hearts/seen/star per slot.

**Tindakan** (per session): action, owner, target date, linked slot, with option to create as a T.A.A. card for the owner (links to CR-05 subtasks).

## Scope
1. Session page lists all slots for that Saturday in order with chair and attendance at the top.
2. 'Edit slot' becomes 'Edit session' + 'Add slot'.
3. Attendance captured by name (tick list from staff directory) with absentee reason.
4. Tindakan table with 'Create T.A.A. task' button (PM/PE and above).
5. Next-month agenda field pre-fills the following session.
6. Existing single-title slots migrate as sessions with one slot.

## Acceptance

2. Each slot has its own discussion thread and Nota link section.
3. Clicking 'Create T.A.A. task' on Tindakan 1 creates a card for Rubmin with target 'Bulan hadapan'.
4. September session shows agenda carried over from August (Amy, then Rubmin/Syafiq continuation).
