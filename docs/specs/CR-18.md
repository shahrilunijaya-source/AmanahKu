# CR-18 – Recurring Auto-Task: Social Activity Every 2 Months (Admin Team)

| Field | Value |
|---|---|
| Module | T.A.A. / Recurring tasks |
| Priority | Medium |
| Tracker status | Open |
| Owner | Shazwan |
| Target | 11 Sep 2026 |
| Run status | In run, session S06. The generic engine is a Wave A foundation, it blocks CR-14, CR-21 and CR-34 |

## Requirement
Amanahku automatically creates a T.A.A. task 'Organise company social activity' for the Administration team (Finance Manager MN as owner, Ain Akilah / Alya / Aminah / Hidayah tagged) once every 2 months, so a social event happens at least 6 times a year without anyone remembering to raise it.

## Why
Social activities only happen when someone pushes for them. A recurring task with an owner, due date and visibility on management dashboards (CR-17) makes it a standing responsibility.

## Scope
1. Recurring task engine (generic): frequency (weekly / monthly / every N months / yearly), start date, owner, tagged members, project tag, lead time, subtasks template. Admin/HR can create other recurring tasks with the same feature.
2. This task: created on the 1st of every odd month (Jan, Mar, May, Jul, Sep, Nov), due end of that month, project tag 'URSB : Culture', priority Medium, label 'Recurring'.
3. Pre-filled subtasks (CR-05): propose 2 to 3 ideas + budget, Director approval, create Event in The Playground (CR-11/16) with all staff as attendees, run it, post photos and lessons learnt.
4. Done rule (all required): linked Event exists and was approved (Director/PM); Event status = Held (set by organiser, not by date); Event date has passed; attendance recorded (at least one Attended per CR-11 states, minimum % configurable); post-event evidence uploaded (photos and/or lessons learnt). A Cancelled or Draft event, or a past-dated event with no attendance, does not satisfy the rule.
5. If overdue, it appears on the Director/HR overdue panel (CR-17). Next occurrence is created regardless of the previous one's status.

## Acceptance
1. On 1 Nov 2026 the task appears on MN's board with the four admin staff tagged and due 30 Nov.
2. Subtasks are pre-filled; completing 'Create Event' links to an Event with all staff as attendees.
3. A past-dated but Cancelled or unattended Event does not close the task; only Approved + Held + attendance + evidence does.
3b. Owner leaves the company, next occurrence goes to the current Finance Manager; HR reassigns any open one at off-boarding.
3c. Skip Nov occurrence with reason, no task created; Jan occurrence still created. Pause, nothing created until Resume.
3d. 1 Jan is a public holiday, task created on the next working day; only one occurrence per period even if the job runs twice.
4. On 1 Jan 2027 the next occurrence is created automatically.
5. HR can set up a second recurring task (e.g. quarterly fire drill) using the same screen.
