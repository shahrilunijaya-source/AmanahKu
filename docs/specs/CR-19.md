## Requirement
Any T.A.A. card that Amanahku creates automatically from another module must also be closed automatically when the thing it represents is finished. Users should never have to manually drag system-generated cards to Done.

## Why
CR-01/10/11/14/18 will generate many cards (events, calendar items, TOT actions, award tasks, recurring tasks). If they need manual closing they become clutter and false 'overdue' noise on the management dashboard (CR-17).

## Rules table

| Card source | Auto-Done when | Notes |
|---|---|---|
| Event attendee card (CR-11) | Attended to Done; Did Not Attend to Archived; invitation withdrawn to Cancelled; no attendance recorded stays 'Pending Attendance' (never auto-closed by event end) | Organiser prompted to record attendance after the event |
| Google Calendar event card (CR-01) | Event end time has passed to Done; event deleted or cancelled in Calendar to Cancelled (calendar) | Never Archived; card and history remain. DEFERRED in the autonomous run |
| TOT Tindakan card (CR-10) | Owner marks Done in T.A.A., or Tindakan row marked Done in session | Two-way; no auto-close by date |
| Awards 'Nominate' task (CR-14) | Nomination submitted, or nomination window closes | Window closed without submission to Archived |
| Awards 'Select' task (CR-14) | Winners published | |
| Recurring task (CR-18) | Its Done-rule met (e.g. linked Event passed) | Next occurrence created regardless |
| Friday Track update task (CR-34) | Closed manually by the owner only | Individual per manager; shows overdue after 5 PM, never scores |
| Parent card with subtasks (CR-05) | All subtasks completed to parent In Review | Done by Reviewer if assigned, else Primary Owner; deletion never triggers |
| Track WBS-linked card (CR-06/07) | WBS task reaches 100% in Track | To confirm. DEFERRED in the autonomous run |

## Common rules
1. Auto-closed cards get an activity log entry 'Closed automatically – <reason>' and a small 'Auto' badge.
2. Auto-closed cards are excluded from overdue counts and from awards like Done & Dusted / Deadline Who? (CR-14) so nobody farms points from system cards.
3. A user can reopen an auto-closed card (e.g. event follow-up); it then behaves as a normal manual card.
4. Auto-Done runs on a scheduled job (every 15 min) plus on the triggering action.
5. Manual cards are never auto-closed by date.

## Acceptance
1. HPE AI Developer Days ends, attendee cards show 'Pending Attendance'; organiser marks Syakir Attended, Done with 'Auto' badge; Kussairi Did Not Attend, Archived.
2. Delete a synced Google Calendar meeting, the card shows Cancelled (calendar), not Archived. DEFERRED.
3. Submit a nomination, the 'Nominate' task disappears from To Do.
4. Auto-closed cards don't count toward Done & Dusted.
5. A normal overdue Task remains open until moved manually.
