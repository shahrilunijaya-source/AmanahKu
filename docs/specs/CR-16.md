## Requirement
Rename the left-panel section Learning to The Playground. Move the Events menu item (currently a top-level entry) into The Playground, so the section contains: Knowledge Bank, TOT Sessions, Events. 'My Profile Test' is removed from here per CR-15.

## Why
Knowledge, TOT Saturdays and external events/trainings are all the same thing, where people explore, share and have fun learning. One section with a playful name matches the culture direction (CR-11/13/14).

## Scope
1. Sidebar label EN: 'The Playground'; BM: to confirm (suggest 'Taman Permainan' or keep 'The Playground' in both).
2. Order inside section: Knowledge Bank, TOT Sessions, Events.
3. Update page titles, breadcrumbs, 'What is this screen for?' text and any notification wording that says 'Learning'.
4. Existing URLs/bookmarks for Learning and Events keep working (redirect).

## Acceptance
1. Sidebar shows 'The Playground' with Knowledge Bank, TOT Sessions, Events as children; no top-level Events item.
2. Toggle EN/BM, label changes accordingly.
3. Old Learning/Events links still open the right page.
4. Icon updated to suit the new name (e.g. a playful icon instead of the book).
