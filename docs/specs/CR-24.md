# CR-24 – Big Deal Alert

| Field | Value |

| Module | Dashboard / Culture |
| Priority | Medium |

| Run status | In run, session S22. Read culture-pack-preamble.md first |

## What
Full-width Dashboard banner (CR-13 component) when something significant happens: project go-live, tender won, claim received, UAT completed, major milestone, client compliment. Example: BIG DEAL ALERT, 'iLPF just completed UAT. Everyone involved may now breathe again.' Shows the team avatars, photos, reactions and a short 'What it took' story written by the PM.

## Rules
Raised by PM and above from the project or T.A.A. card ('Mark as Big Deal'); Director can also raise. Types are fixed (list above + 'Other'). Optional link to the Track milestone / tender record. Stays 3 days, then archived to a 'Wins' page in The Playground. Client compliments require the source (email/letter) attached, names of client staff hidden unless approved.

## Acceptance
PM marks 'iLPF UAT completed' as Big Deal with 3 photos, banner on all dashboards with team avatars and story; reactions work; visible in Wins page after 3 days.
