## What
Replace generic emoji reactions across T.A.A., Wall, Events, Awards, Wins and Office Requests with Unijaya's own set: Power / Legend / Chef's Kiss / Noted With Fear / Send Help / Respect / How Did You Do This? / Claim Bila?, each with a small custom icon.

## Rules
Set is HR/Admin editable (max 10, add/retire, never rename an existing one so history stays readable). Reactions count once per person per item. Reactions are just reactions, 'Send Help' notifies nobody. A separate, explicit Request Help action on a card (choose person, short message) exists for real escalation and creates a Helper tag (CR-04). Reactions never feed awards except Chief Hype Officer's unique-colleague count.

## Acceptance
Reaction picker shows the 8 custom reactions everywhere; 'Send Help' sends no notification; 'Request Help' button on a card does. HR adds a 9th reaction; retired reaction still shows on old items.
