Applies to CR-11, 13, 14, 15, 17, 20, 22, 23, 24, 28, 29, 31.

| Field | Value |
|---|---|
| Module | Dashboard |
| Priority | High |

| Owner | Shazwan |
| Target | 11 Sep 2026 |
| Run status | In run, session S04. Also retrofits CR-13, CR-15, CR-20 and CR-23, which were built before this rule existed |

## Requirement
All new dashboard features are added into the existing Dashboard. The current cards (Current month summary, Daily clock log, Pending tasks, My leave summary, My work summary, My calendar, Team attendance, Notice board, My claim summary) stay exactly where they are. **Do not build a new dashboard. Nothing existing is removed, renamed or reordered.**

## Placement
**Top, full width** (only when active, otherwise not rendered):
1. Moments banner (Birthday CR-13, Big Deal CR-24, Victory Bell CR-28, Holiday eve CR-20, Wrapped CR-22, one slot, rotates if several).
2. Management panels (CR-17), Director / HR / Sr Mgr only.
3. Awards carousel (CR-14), from the 1st working day until the 7th.

**Left column,** inserted after Pending tasks: Friday sign-off (CR-29, Friday 3 PM to Monday 9 AM only).
**Left column,** after My work summary: My working style card (CR-15).
**Right column,** inserted after Team attendance: Events card (CR-11).
**Inside Notice board:** Plot Twist result (CR-25) on Fridays.
**After Notice board:** Flowers feed (CR-23).
**Greeting line:** easter-egg text (CR-31) replaces the 'not clocked in yet' line only when triggered.

On a normal day with nothing active, the Dashboard opens identical to today. Users with 'Keep it plain' see text-only versions of the new cards.
