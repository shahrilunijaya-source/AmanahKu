## Requirement
Add a new top-level left-panel item (below Workplace) where any staff can report office issues or request items, e.g. bulb not working, company car due for service, coffee finished, add items to pantry, printer toner, aircond leaking. It works as a shared wishlist / to-do for the Admin team, with each request routed as a T.A.A. card to the Admin team queue.

## Name
EN: Office Requests / BM: Permintaan Pejabat (alternatives: 'Ask Admin', 'Pantry & Fixes'). Icon: wrench/basket.

## Why
Today these are WhatsApp messages that get lost; nobody knows if it was done, and the same coffee gets requested by five people. One board gives visibility, dedupe and a record of what admin handled.

## Scope
1. **Raise a request** – form: category (Facilities repair / Vehicle / Pantry & supplies / IT & equipment / Cleaning / Other), title, description, optional photo, location (office/floor/room or vehicle plate), urgency (Low / Normal / Urgent, Urgent needs reason). Duplicate check: shows similar open requests so the person can +1 / upvote instead of re-raising.
2. **Public board** (all staff can see): Open / In Progress / Done, with upvotes, comments, and 'Admin note' (e.g. 'ordered, arriving Thu'). Pantry wishlist view = list sorted by votes.
3. **Routing** – every request creates a T.A.A. card owned by the Admin team role (CR-18 engine ownership; Finance Manager MN as default Primary Owner, admin staff tagged as helpers); Urgent also notifies MN and Director. Admin can reassign within the team, set ETA, mark Done with a closing note; requester gets notified and can reopen within 3 days if not fixed.
4. **Recurring items** – pantry staples (coffee, milk, tissue) can be set as recurring restock tasks (CR-18) so they're ordered before they run out; staff '+1' just bumps priority.
5. **Vehicle** – car service requests capture plate, mileage, last service date; reminder task auto-created at service interval (CR-18).
6. **Reporting** – Insights: requests per month by category, average time to close, top-voted items; Completed Admin requests count as normal completed cards under Done & Dusted.
7. Requests are system-routed but human-closed, no auto-Done (CR-19 not applied).
